Use on Nothing Phone 3

Install as native PWA or build APK

Method 1: Direct Install (Instant) Recommended
  1. Ensure your Nothing Phone 3 is connected to the same Wi-Fi.
  2. Open Chrome on your phone and browse to:
    http://192.168.1.8:8080
  3. Tap the three dots (⋮) in Chrome and tap "Install app" (or "Add to Home screen").
  4. CheckNotes installs directly to your app drawer/home screen with full offline support and zero browser bars!
Method 2: Standalone .APK Package

A complete, pre-configured Android Studio project is prepared in the android/ directory. You can compile it into a release APK using Android Studio, or via the included GitHub Actions workflow!
